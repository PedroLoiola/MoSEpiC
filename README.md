# MoSEpiC — Modelo de Simulação Epidemiológica por Compartimentos

Versão ajustada do MoSEpiC v1.1 para GitHub Pages.

## Principais ajustes

- Remoção dos badges de cabeçalho solicitados.
- Remoção do texto descritivo da versão 1.1 no cabeçalho.
- Padronização dos títulos dos parâmetros em letras maiúsculas.
- Ajuste do rótulo: **R0 — ALVO DIDÁTICO EM POPULAÇÃO SUSCETÍVEL**.
- Inclusão da marca Creative Commons BY-NC-SA 4.0 na seção de licença.
- Inclusão de botão para baixar a curva do gráfico em PNG.

## Hospedagem no GitHub Pages

Envie o conteúdo desta pasta para a raiz do repositório e ative: Settings → Pages → Deploy from a branch → main → /root.
